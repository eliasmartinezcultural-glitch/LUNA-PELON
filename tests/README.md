# Pruebas del núcleo

Estas pruebas protegen contratos que no deben romperse mientras crece el mundo.

## Ejecutar

```bash
npm test
```

El validador estructural también ejecuta estas pruebas mediante `npm run check`.

## Cobertura actual

- estado y saneamiento;
- modelo lógico del mundo;
- IDs únicos de entidades;
- colisiones y movimiento;
- consultas espaciales.

No sustituyen todavía la prueba visual en navegador. Esa será una capa posterior de verificación.
